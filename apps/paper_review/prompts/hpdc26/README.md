# HPDC 2026 Prompt Pack

This folder contains the first draft of the HPDC-specific reviewer prompt pack for the ProtoNeo PC Panel product.

## Assembly

For each agent, compose the final system prompt as:

1. `shared.md`
2. the role-specific overlay (`technical.md`, `novelty.md`, `clarity.md`, `skeptic.md`, `artifact.md`, or `meta.md`)

## Intended mode

- author-facing
- pre-submission
- conference-calibrated
- evidence-grounded

## Notes

- The prompts are designed around the local HPDC 2026 CFP and offline review form.
- `artifact.md` is optional and should be enabled when an artifact appendix, AD/AE appendix, or strong reproducibility claim is present.
- `meta.md` is used after independent review and deliberation, not during the first-pass blind review.
